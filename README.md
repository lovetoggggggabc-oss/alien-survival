# 낯선 별의 밤 — Alien Survival

외계 행성 2D 모바일 생존 시제품. 낮 9분 동안 채집·채굴·건설하고, 밤 4분 동안 기지를 방어합니다.

## 바로 실행

https://lovetoggggggabc-oss.github.io/alien-survival/

모바일 세로 화면 브라우저에 맞춰져 있으며, 진행 상황은 해당 브라우저에 자동 저장됩니다.

## 모바일 조작

- 왼쪽 조이스틱: 이동. 아래로 밀고 채집하면 발밑을 팝니다. 사다리 근처에서 위로 밀면 올라갑니다.
- 오른쪽: 채집 / 공격 / 점프. 채집과 공격은 길게 누를 수 있습니다.
- 지하 블록 터치 후 채집: 원하는 칸을 지정해 팝니다.
- 공격이 적에게 맞으면 해당 적 위에 피해량 숫자가 표시됩니다. 몬스터는 앞에 놓인 돌·흙·나무 블록을 여러 번 때려 부술 수 있습니다.
- 오른쪽 위 지도: 산·언덕·깊은 동굴, 건물 위치와 자신의 현재 위치를 확인합니다.
- 좌표는 시작 지점을 **X 0 · Y 0**으로 표시하며 한 칸이 20픽셀입니다. 오른쪽으로 갈수록 X가, 아래로 내려갈수록 Y가 커집니다.
- 방향을 향하면 채굴할 블록에 빛나는 테두리와 진행 막대가 나타납니다. 때린 블록은 잠깐 흔들립니다.
- 가방에서 돌·흙·나무 **설치** 선택 후 가까운 빈 칸 터치: 블록을 놓습니다. 다른 블록에 닿아야 놓을 수 있습니다. 캐면 가방으로 돌아옵니다.
- **가방**은 마인크래프트처럼 아이템을 칸으로 보여줍니다. 칸을 누르면 아래에서 설치·사용·장착할 수 있고, 위에서 현재 장비를 확인할 수 있습니다.
- 제작소에서 **보관 상자**를 만든 다음 가방에서 상자를 선택해 평평한 지상에 놓습니다. 설치한 상자를 터치하면 재료·식량·사다리·회복약을 넣고 꺼낼 수 있습니다. 종류별 최대 64개까지 보관하며 저장됩니다.
- 가방의 장비 칸은 **헬멧·갑옷·바지·신발 / 곡괭이·무기**로 나뉩니다. 제작소에서 각 부위를 만들고 아이템 칸을 눌러 장착합니다. 탐사 등불도 별도로 장착할 수 있습니다.
- 화면 왼쪽 위에서 체력과 허기 바를 확인할 수 있습니다. 허기는 시간이 지나면 줄어들며, 가방에서 식량을 골라 먹으면 30 회복합니다. 허기가 0이면 체력이 줄어듭니다.
- 설정의 **리스폰**을 누르면 시작 지점 X 0 · Y 0으로 돌아가 체력을 회복합니다. 가방, 장비, 건물, 상장은 유지됩니다.
- 상단 **🏆 상장**에서 채굴·탐험·건설·생존 목표와 획득한 상장을 확인할 수 있습니다.
- 설정(⚙): 조이스틱 크기를 80~160px로 조절하며 자동 저장합니다. 진행 상황 수동 저장도 있습니다.
- PC: A/D 이동, S+E 아래 채굴, W 사다리, Space 점프, E 채집, F 공격, I 가방.

## 설계도와 제작

1. 처음에는 **설계도 작업대**만 설치할 수 있습니다. 설계도 창에서 선택하고 지상 빈 곳을 터치합니다.
2. 채집 버튼으로 재료를 현장에 넣거나 운반 동료에게 맡기고, 건설을 마칩니다.
3. 완성된 설계도 작업대 가까이에서 **설계도 제작** 창을 열어 제작소·침대·재배실·방벽의 설계도를 만듭니다.
4. 만든 설계도만 **설계도** 창에 표시됩니다. 배치하면 설계도 한 장이 소비됩니다.
5. **제작소**를 별도로 건설해야 아이템 제작 창에서 강화 곡괭이·강화 무기·수정 창·헬멧·갑옷·바지·신발·등불·사다리·회복약·보관 상자를 만들 수 있습니다.

맵 가로 길이는 12,280픽셀, 블록은 20픽셀입니다. 플레이어도 블록 크기에 맞게 줄었습니다. 흙·나무·돌·광물마다 채굴에 필요한 횟수가 다르고 강화 곡괭이로 더 빠르게 캘 수 있습니다. 기존 브라우저의 진행 상황, 채굴한 땅과 설치한 블록·장비는 새 격자에 맞춰 이전됩니다.
지하 동굴의 깊이를 늘렸으며 기존에 판 블록과 설치한 사다리는 보존됩니다.

완성된 침대 한 개당 동료 한 명을 모집할 수 있고, 동료에게 운반·건설/채집/경비 역할을 지정할 수 있습니다. 돌, 흙, 금속, 발광 수정은 지하에서 얻고, 나무와 섬유·식량은 지상에서 채집합니다.

지하 몬스터, 정교한 동료 길 찾기, 멀티플레이는 아직 구현되지 않았습니다.
