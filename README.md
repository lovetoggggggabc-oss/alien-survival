# 낯선 별의 밤 — Alien Survival

외계 행성에서 낮에는 자원을 모으고 땅을 파서 지하를 탐험하며, 밤에는 기지를 방어하는 모바일 세로 화면 2D 생존 시제품입니다.

## 바로 실행

https://lovetoggggggabc-oss.github.io/alien-survival/

모바일 브라우저에서 세로로 열어 플레이할 수 있습니다. PC에서는 `index.html`을 브라우저에서 열어도 됩니다. 자동 저장은 브라우저의 로컬 저장소를 사용합니다.

## 모바일 조작

- 왼쪽 조이스틱: 좌우 이동. 아래로 밀고 채집하면 발밑을 팝니다. 사다리 근처에서는 위로 밀어 올라갑니다.
- 오른쪽 버튼: 채집 / 공격 / 점프. 채집과 공격은 길게 누를 수 있습니다.
- 지하 타일 터치: 채굴할 칸을 지정한 뒤 채집 버튼으로 팝니다.
- 가방: 자원과 장비 확인, 회복약 사용, 사다리 배치.
- 설계도: 제작소, 침대, 재배실, 방벽을 지상에 배치.
- 제작: 완성된 제작소 **가까이** 있어야 강화 도구, 등불, 사다리, 회복약을 만들 수 있습니다.
- 동료: 완성된 침대 1개당 동료 1명을 식량 2개로 모집하고 운반·건설 / 채집 / 경비 역할을 지정합니다.

PC 키보드: A/D 이동, S/아래 방향키를 누른 채 E로 아래 채굴, W/위 방향키로 사다리 오르기, Space 점프, E 채집, F 공격, I 가방.

## 게임 흐름

낮 9분 / 밤 4분 주기입니다. 설계도를 지상에 놓으면 건설 현장이 생기고, 가진 재료를 채집 버튼으로 넣거나 운반 동료가 옮깁니다. 재료가 다 모이면 플레이어나 동료가 건설합니다. 처음 가진 자원으로 제작소 설계도를 설치할 수 있습니다. 땅을 파서 금속과 발광 수정을 찾아 제작소에서 장비를 강화하세요. 재배실은 새 낮마다 식량을 생산합니다.

현재는 간단한 시제품입니다. 지하 몬스터, 정교한 동료 길 찾기, 여러 행성, 장비 내구도, 멀티플레이는 구현되지 않았습니다.
