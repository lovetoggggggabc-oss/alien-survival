# 낯선 별의 밤 (Alien Survival)

외계 행성에서 낮에는 채집하고 밤에는 기지를 지키는 2D 픽셀 생존 게임의 첫 플레이 가능한 시제품입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 빌드나 설치가 필요 없습니다. 모바일 터치 버튼도 지원합니다.

## 조작

- `A` / `D` 또는 화면 화살표: 이동
- `E` 또는 ⛏ 버튼: 근처 자원 채집, 건설 현장에 가진 재료 넣기
- `F` 또는 ⚔ 버튼: 근처 적 공격
- 설계도 선택 후 땅 클릭: 건설 현장 배치
- 동료 역할 버튼: 운반·건설 → 채집 → 경비 순서로 변경
- 시간 ×10: 낮과 밤의 전환을 빠르게 시험

## 핵심 규칙

- 낮 9분, 밤 4분. 밤에는 외계 생물이 나타납니다.
- 침대는 광석 3, 금속 2, 섬유 2; 농장은 광석 2, 섬유 5; 방벽은 광석 6, 금속 3을 사용합니다.
- 설계도만 배치하면 완성되지 않습니다. 플레이어나 운반 역할 동료가 재료를 넣고, 건설 시간이 지나면 완성됩니다.
- 완성된 침대 하나마다 동료 한 명을 모집할 수 있습니다. 모집 시 식량 2개를 씁니다.
- 새 낮이 되면 식량을 소비하고 완성된 농장마다 식량 3개를 얻습니다.
- 진행 상황은 브라우저에 자동 저장됩니다.

초기 시제품으로, 타일 채굴·복층 지하·멀티플레이·정교한 동료 경로 찾기는 이후 개발 대상입니다.
